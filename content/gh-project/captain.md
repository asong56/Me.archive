# What is Captain

Captain is a chromoium extension that contains the function of
- Omni
- WebRTC Control
- Chrome UA Switcher
- Proxy SwitchyOmega
- LeechBlockNG
- Extensity
- Page Assist

---

I made it because I use these extensions everyday, but the design is different and also some are very large and heavy.
So I kept the useful parts and made one single extension, using my [acdn design](https://github.com/asong56/acdn),
and made this extension which is only 2430KB in total, which is really small compared to the total size of more than 50MB of the original ones.

---

I called it captain because it uses one single panel to control all functions, which is very simple but powerful, like a captain that leads you on sea.
I added the AI chatting part to Captain because I found that I don't like an additional chat extension or a local chat app on my computer.
It should support localhost, llm api and some other things, maybe skills?
